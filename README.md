# NutriCalc Pro 3.0.0

Исправленная версия исходного HTML Георгия Образцова. За основу взят `nutricalc_pro.html`, а не переработанный интерфейс версии 2.0.

Сохранены исходные вкладки «Калькулятор», «Рацион», «Справочник», расположение формы и карточек, две диаграммы canvas, цвета, типографика, оформление меню и подвал. Новых режимов, экранов и настроек не добавлено. Исправлены только расчёты, проверка данных, состояние меню, доступность и печать. Короткие сообщения о неверном вводе и фактических отклонениях находятся в существующих блоках.

## Исправления

- Пустые значения не подменяются скрытыми значениями по умолчанию. Диапазоны полей проверяются перед расчётом, дробные рост и вес допустимы.
- Формула Миффлина — Сан Жеора ограничена возрастом исходной выборки 19–78 лет. Начальное значение возраста — 30 лет. Это необходимое исправление области применения формулы; детская формула не добавлялась. Формула оценивает расход энергии в покое, не измеряет его индивидуально.
- Убрано промежуточное округление при расчётах. БЖУ 25/30/45% согласованы с целевой энергией.
- Подбор учитывает калории и БЖУ. Проверяются 625 сочетаний блюд; размеры порций уточняются координатным поиском на сетке 10 г. Ограничения — 50–150% базовой массы блюда. Это параметры модели, не нормы питания. Глобальная оптимальность не доказана.
- В исходном разделе «Рацион» показываются фактические суммы и отклонения. Превышение допуска ±10% явно отмечается. Если среди найденных вариантов только один попадает в допуск, обновление не обещает разнообразие, а повторяемость объясняется.
- Калорийность блюда вычисляется по фактической порции, не копируется из цели. Суммы считаются без промежуточного округления, округляется только вывод.
- Дневное меню соответствует понедельнику того же недельного плана. Переключение «День / Неделя» не меняет блюда. План сохраняется локально в браузере. Ошибка localStorage не останавливает приложение.
- Недоступность иконок не блокирует расчёт. Lucide включён локально; стили исходного Tailwind сохраняются без изменения дизайна.
- Убраны фиксированные количества ингредиентов в масштабируемых названиях блюд. Непроверенные численные нормы в справочнике заменены ссылкой на источник возрастных рекомендаций. Сами карточки и фильтры сохранены.
- Исправлены подписи полей и названия вкладок для средств доступности. Варианты пола доступны с клавиатуры. Печать использует чёрный текст на белом фоне и выводит выбранное меню.

Пищевая база перенесена из исходного проекта. Подтверждённых рецептур нет; корректность алгоритма не подтверждает точность пищевой базы и не делает меню медицинским назначением. Нормы витаминов, минералов, аллергии и заболевания не оптимизируются. Работа над кодом этой версии выполнена с помощью ИИ; самостоятельное понимание и проверка Георгием остаются отдельной частью проекта.

## Файлы

`index.html` — исходная структура и оформление; `app.js` — расчётное ядро и обработчики исходного интерфейса; `styles.css` — сохранённые исходные стили Tailwind; `tests.cjs` — проверки; `.nojekyll` — статическая публикация. Иконки включены в HTML. Шрифт Inter может загружаться из Google Fonts; при его недоступности применяется исходный запасной шрифт sans-serif, расчёты продолжают работать.

Отдельно подготовлен автономный HTML с кодом и стилями внутри одного файла.

## Проверка

`node tests.cjs`

16 проверок: исходные вкладки и поля, запуск без иконок, согласованность баз, диапазоны и пустой ввод, дробные параметры, независимый расчёт формулы, 625 сочетаний, численные инварианты на 20 сценариях, сохранение при переключении, восстановление и повреждение localStorage, очистка устаревших результатов, фактическая калорийность ограниченных порций, справочник и поиск.
